# Minimal OptiView Player Smart TV example

Minimal OptiView Player Smart TV example is a barebone example of how to integrate OptiView Player in a Smart TV SDK.

For a more advanced example (with UI), check out the `example-with-ui` directory in the root directory of the project.

## OptiView Player library

`npm install` in the `tizen` folder copies the OptiView Player library from the `theoplayer` npm package to `libs/`. This app uses the chromeless build (`THEOplayer.chromeless.js`).
