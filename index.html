How to run the samples

The root npm start runs the static reference apps directly, without a build. Every other sample is its own npm project: run the commands on its card from the repository root, or follow its README.

More live demos are on the OptiView Player examples page.

License

Without a license, OptiView Player only plays on localhost. To play on other domains, get a license on THEOportal and set it in the sample, as its README describes.

Integrations

Each integration is a separate npm project with a webpack build. Run the commands in a terminal and open localhost:8000.

  • Uplynk

    Uplynk playback with ad breaks, asset info and ad skipping. Needs a license with Uplynk enabled.

     cd reference-apps/uplynk-app npm install npm run build npm start

  • Wowza Streaming Cloud

    Show a placeholder while a live stream is offline and start playback when it goes live.

     cd reference-apps/wowza npm install npm run build npm start

  • Wowza backup streams

    Switch to the next online backup stream when the primary stream stops.

     cd reference-apps/wowza-backup-streams npm install npm run build npm start

Bundlers

Each bundler sample is a separate npm project. Run the commands in a terminal; the README lists the URL to open.

  • Vite

    Bundle the theoplayer package with Vite. The commands are for JavaScript; use the typescript folder for TypeScript.

    README: JavaScript, TypeScript

    cd bundlers/vite/javascript npm install npm run dev

  • webpack

    Bundle the theoplayer package with webpack. The commands are for JavaScript; use the typescript folder for TypeScript.

    README: JavaScript, TypeScript

    cd bundlers/webpack/javascript npm install npm run build npm run serve

  • Rollup

    Bundle the theoplayer package with Rollup. The commands are for JavaScript; use the typescript folder for TypeScript.

    README: JavaScript, TypeScript

    cd bundlers/rollup/javascript npm install npm run build npm run serve

  • Parcel

    Bundle the theoplayer package with Parcel. The commands are for JavaScript; use the typescript folder for TypeScript.

    README: JavaScript, TypeScript

    cd bundlers/parcel/javascript npm install npm run build npm run serve

Frameworks

Each framework sample is a separate npm project with its own dev server. Run the commands in a terminal; the README lists the URL to open.

  • React

    A React 19 component built with Vite.

     cd frameworks/react npm install npm run dev

  • Next.js

    A Next.js App Router page that renders the player on the client only.

     cd frameworks/nextjs npm install npm run dev

  • Angular

    A standalone Angular component.

     cd frameworks/angular npm install npm run dev

  • Vue

    A Vue 3 component built with Vite.

     cd frameworks/vue npm install npm run dev

  • Nuxt

    A Nuxt 4 component rendered inside <ClientOnly>.

     cd frameworks/nuxt npm install npm run dev

Smart TV

Build the app here, then install it on a TV or emulator as described in its README.

  • LG webOS

    A minimal app and an app with a remote-control UI, packaged with the webOS CLI.

    Variant: example with UI

    cd smart-tv/webos npm install npm run build

  • Samsung Tizen

    A minimal app and an app with a remote-control UI, built with Tizen Studio.

    Variants: minimum example, example with UI

    cd smart-tv/tizen npm install npm run build

  • Lightning

    A Lightning app with a source list and play/pause controls.

     cd smart-tv/lightning npm install npm run build npm run serve
